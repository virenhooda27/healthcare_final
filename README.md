# AI-Powered Medical Diagnosis Assistant

An intelligent healthcare application designed to streamline disease diagnosis using advanced **machine learning** and **natural language processing (NLP)** techniques. Built with a modern web stack and secure backend services, the system supports both image-based and text-based diagnostic features.

## 🔍 Features

### 🩺 Image-Based Disease Prediction
Leverages **VGG transfer learning** to classify diseases from images of body parts uploaded by users. This model enables accurate and fast visual diagnosis, enhancing early detection and response.

### 💬 Symptom-Based Diagnosis (NLP)
Utilizes **natural language processing** to understand and interpret user-described symptoms in plain text. Offers instant, AI-generated predictions and suggestions based on symptom analysis.

### 📁 Medical Report & Prescription Management
Enables users (doctors and patients) to securely **store, retrieve, and manage** medical reports and prescriptions. Built on **Supabase**, ensuring data confidentiality and accessibility across sessions.

### 🔐 Role-Based Authentication
Implements a secure **role-based access control system** distinguishing between patients and doctors. Provides personalized features and ensures protection of sensitive medical data.

## 🛠️ Tech Stack

- **Frontend:** React.js + Tailwind CSS
- **Backend:** Flask (Python)
- **Database & Auth:** Supabase
- **ML/NLP Models:** VGG (Transfer Learning), NLP pipelines

## 🚀 Purpose
This assistant aims to democratize early disease detection, making healthcare more accessible, proactive, and personalized through AI.
